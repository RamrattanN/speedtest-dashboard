# Roadmap

## Validated

- Cross-platform Python collector and dashboard
- Local CSV retention and monthly archives
- Native 60-second dashboard redraw
- Ramrattan-branded dashboard and right-side Help
- Unsigned macOS Intel Pilot 3 application and disk image
- Packaged-app smoke test in GitHub Actions
- Unsigned Windows x64 Pilot 1 installer and installed-app smoke test

## Near-term

- Complete controlled Pilot 3 acceptance with additional Intel Mac users
- Add explicit collection-engine and last-success health status
- Refine installer and first-launch guidance from pilot feedback
- Complete Windows Pilot 1 acceptance on representative Windows x64 PCs

## Later releases

- Apple silicon application package
- Optional code signing and Apple notarization when paid signing is justified
- Launch-at-login option
- Automatic application updates
- Persisted dashboard preferences
- Multiple host and server visualisation
