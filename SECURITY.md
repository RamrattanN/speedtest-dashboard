# Security policy

## Supported versions

Security fixes are considered for the latest published stable Speedtest Monitor release.  Older releases and release candidates are not actively supported.

## Reporting a vulnerability

Please report suspected vulnerabilities privately.  Use GitHub's [private vulnerability reporting](https://github.com/RamrattanN/speedtest-dashboard/security/advisories/new) when available.  If it is unavailable, email **info@ramrattan.com** with the subject **speedtest-dashboard security report**.

Include the affected version or commit, clear steps to reproduce, a proof of concept if available, the possible impact, and a way to contact you.  Please do not publish exploit details in an issue or pull request while a report is being investigated.  Do not include personal speed-test history, device identifiers, or credentials in a report.

The maintainer will acknowledge and review the report, coordinate a fix and disclosure where appropriate, and publish a GitHub security advisory when warranted.  Reasonable credit will be given upon request after a fix is released.  No fixed response or resolution time is promised.
